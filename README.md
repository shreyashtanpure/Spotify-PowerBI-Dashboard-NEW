# Spotify-PowerBI-Dashboard-NEW
🎧 Spotify Music Analytics Dashboard | Power BI

------------------------------------------------------------------------

📌 Project Objective

Design and develop a fully interactive Spotify Analytics Dashboard using
Power BI that transforms raw music data into meaningful and actionable
business insights through advanced data modeling and DAX.

------------------------------------------------------------------------

📊 Problem Statement

Music streaming platforms generate massive datasets. This project aims
to:

-   Analyze song and artist performance
-   Identify popularity trends over time
-   Compare album types (Single vs Album vs Compilation)
-   Evaluate explicit vs non-explicit content distribution
-   Generate insights using interactive visualizations

------------------------------------------------------------------------

🛠️ Technical Implementation

Data Modeling

-   Star Schema Approach
-   Fact Table: Songs Dataset
-   Dimension Tables: Artist, Album Type, Date
-   Optimized relationships for efficient filtering

------------------------------------------------------------------------

DAX Measures Created

-   Distinct Songs
-   Count of Artists
-   Average Popularity
-   Average Duration (Minutes)
-   Max Popularity
-   Min Popularity
-   Monthly Popularity Trend
-   Album Type Distribution
-   Explicit Content Count

Functions Used: CALCULATE(), DISTINCTCOUNT(), AVERAGE(), SUMX(),
FILTER(), Time Intelligence Functions

------------------------------------------------------------------------

📈 Dashboard Features

-   Multi-page Navigation (Home, Overview, Artist, Songs)
-   Dynamic Slicers (Artist-level filtering)
-   KPI Cards for key metrics
-   Monthly & Yearly Trend Analysis
-   Interactive Charts (Bar, Donut, Line)
-   Spotify-inspired Dark UI Theme

------------------------------------------------------------------------

📊 Key Insights

-   Identified top-performing artists based on popularity score
-   Compared engagement between album releases and singles
-   Observed seasonal trends in music popularity
-   Analyzed explicit vs non-explicit content distribution
